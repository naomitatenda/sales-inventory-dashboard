# Sales and Inventory Dashboard

## Project Overview
An interactive Sales and Inventory Dashboard developed using Microsoft Power BI to analyse sales performance, monitor revenue, and track inventory levels.

## Project Objectives
- Monitor total revenue and sales performance.
- Analyse product and category performance.
- Track stock on hand and reorder levels.
- Identify products that require restocking.
- Explore sales data using interactive filters.

## Tools and Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Microsoft Excel / CSV (where applicable)

## Dashboard Features
- Revenue and sales KPI cards.
- Product sales charts.
- Category and date slicers.
- Inventory table with stock status.
- Interactive data filtering.

## Testing
A test plan was prepared to evaluate:
- Accuracy of revenue and sales calculations.
- Category and date slicer functionality.
- Inventory quantities and reorder levels.
- Stock status calculations.
- Dashboard layout and usability.

Test results should be recorded in the accompanying requirements and testing document.
